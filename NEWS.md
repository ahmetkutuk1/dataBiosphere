# dataBiosphere 0.1.0

* First public release.
* `metaphorMatrix(signal_id, data_type)`: deterministic 12-signal x
  3-family (fluvial, arboreal, celestial) matrix with faithfulness-forbidden
  implications.
* `truthOverlay(...)`: in-frame badge and closing card that keep the literal
  finding (effect size, 95% CI, n) recoverable in every frame.
* Severity Threshold enforced: mortality / illness / trauma findings cannot be
  Tier 3 (game).
